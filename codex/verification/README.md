# Verification tools

Build generated native sources with `python3 -B codex/build.py` first. The portable runner executes original Swift assertions with a shim, not official XCTest. The full visual runner compares every manifest frame at three sizes and a finite static card matrix using owned bitmap contexts; it does not control windows or screens. Pillow is required for contact sheets. These tools generate machine-local evidence under codex/evidence/, which is ignored by Git.

verify_mcp_plugin.py is an installed-environment integration check: it requires the companion, active Codex account, local plugin registration and the optional bundled Node runtime for JS syntax checking. It is separate from the offline Python unit suite. test_mcp_bridge.cjs requires Node and uses a controlled bridge fixture, not a live-host UI acceptance claim.
