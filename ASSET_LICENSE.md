# Animation import converter (0.6.0+)

The standalone application contains a separately built minimal FFmpeg 7.1 converter (LGPL 2.1 or later), statically linked with libvpx 1.14.1 (BSD) and libwebp 1.4.0 (BSD). No GPL/nonfree components are enabled. Complete notices and the source/recipe inventory are retained in codex/media-licenses and Resources/media/licenses. Exact sources and build steps are pinned in codex/media-lock.json and codex/build_media.py. Corresponding source archives and the build recipe are provided alongside each release. The imageio FFmpeg binaries are NOT redistributed in the application.
