# Codex 大肥鱼完整动画库设计

目标：将 PC2005-cloud/dsh-pet 固定版本 34cf7ec4dd1ca99a9a9ac5bcb4571d887862e226 的 106 个动画全部提供给现有 Codex 原生桌宠。保持 Codex 状态、额度倒计时、人工审批 Hooks、设置入口和用户现有配置。

## 方案与选择
由实现者选择继续使用 Swift/AppKit + 透明 WebP 帧，扩展现有模型；相较重写 Electron 播放器，可保留已验收的拖动、点击穿透、任务卡和插件入口。转换和导入使用固定版本 FFmpeg，保留独立可执行程序及全部许可，构建双架构包。不得改变人工审批。

## 功能和边界
- 106 个原视频都有完整帧序列和中文名称，既有 16 个语义动作别名保持兼容；不冒充 106 个角色。
- 原版分层权重：待机 10、转身 5、移动 5、小动作 20、玩耍 20、吃什么 16、时节 14、文字 10。分类内均匀抽选、文字不镜像，五种点击动作；六档额度动作使用真实已用百分比。
- 右键按分类点播全部动作；点播只播一次，完成后恢复最新 Codex 状态。拖动和审批状态可打断装饰动作。移动遵守动作起止保留时间、尺寸缩放和屏幕可见范围。
- 设置提供动画库点播、角色包选择、上游格式导入。支持 pet/<名>-config.json 配合 pet/<名>-animation/*.webm；每包独立配置和素材。没有额外内置角色时如实显示。
- 导入只读用户选择的本地包；限制体积、路径、数量和转换时长，拒绝符号链接、路径穿越及损坏素材，失败不改变当前角色。ZIP 及路径导入由本机设置入口发起。
- 图片按需读取，解码缓存有界；扩充素材不将全部动画加载到内存。
- 原角色保持现有尺寸语义，完整视频画布不得裁掉道具；记录源哈希、转换参数和版权。没有原版动画的自定义包仅使用包内动作，不借用原角色帧。

## 验证
自动验证完整 106 项与每帧可解码、有透明度、源哈希、分类引用，动作仲裁和权重边界、移动边界、导入失败回滚和路径隔离、设置/MCP/额度/Hooks 回归。双架构安装包分别构建并验证；Intel 仅 Rosetta 测试。原生窗口人工操作不能由无界面测试冒充，未验收项明确列出。
