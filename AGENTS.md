# Repository instructions

- Use Install.command or codex/setup.py for source installation; no npm publishing.
- Preserve upstream code and asset license notices.
- Do not commit credentials, user settings, local application bundles, generated native source copies, or personal verification evidence.
- Run the Python adaptation tests for relevant code changes. UI screenshots and protocol checks are separate evidence.
- Do not claim untested platform or host functionality. Source install currently targets macOS only.
- Never force push, change repository visibility, or overwrite unrelated remote history without explicit user instructions.
